How we build: Review-to-Release

  1. CollectGather real user reviews of competing apps in the category.
  2. ClassifySort complaints and requests into concrete, fixable problems.
  3. SpecifyTurn the top problems into a feature spec and acceptance checks.
  4. Build with ClaudeImplement the changes by vibe coding with Claude as the main coding agent.
  5. VerifyRun automated checks and device tests before anything ships.

We first ran this pipeline on Hanco Note, reviewing 3,739 competitor app reviews end to end. Next, we're moving it onto the Claude API so it can run for every product.
